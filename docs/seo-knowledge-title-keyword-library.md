# SEO / GEO Content Library

This project now includes three reusable content assets:

- `src/data/knowledgeBase.ts`
- `src/data/titleLibrary.ts`
- `src/data/keywordLibrary.ts`

Use them as the source of truth for future blog posts, service page expansion, FAQ copy, multilingual SEO pages, and AI-search-ready content.

## How to use the knowledge base

The knowledge base is built around real client intent instead of broad topic labels.

Each entry includes:

- the audience
- the exact question we want to answer
- the search intent
- the recommended answer angle
- key points to include
- compliance notes to repeat
- internal links to route authority inside the site

Recommended usage:

1. Pick one knowledge base entry.
2. Expand it into one full article or one service-page section.
3. Keep the compliance notes visible in the content.
4. Add the listed internal links before publishing.

## How to use the title library

The title library is meant for editorial production.

Use it to:

- draft new blog posts
- create FAQ pages
- expand service supporting pages
- create localized Chinese / Traditional Chinese / English variants

Editorial rule:

- Prefer one primary query per article.
- Do not mix relationship, debtor, and locate intents in one post unless the article is a general guide.
- Keep titles direct and search-oriented.

## How to use the keyword library

The keyword library is organized by page cluster and target URL.

Recommended usage:

1. Choose the target page first.
2. Use one or two `primaryKeywords` in the title, H1, intro, and meta description.
3. Use `secondaryKeywords` naturally in H2s, body copy, FAQ blocks, alt text, and anchor text.
4. Keep wording natural and avoid keyword stuffing.

## Suggested content production order

1. Relationship cluster
   This usually converts well because users have urgent emotional and trust-based intent.
2. Locate cluster
   Good for overseas Chinese and family reconnection traffic.
3. Background cluster
   Useful for trust-building and broader information intent.
4. Debtor cluster
   Strong commercial intent and easier service qualification.
5. Compliance cluster
   Important for trust, GEO, and filtering bad-fit leads.

## GEO writing notes

For AI-search visibility, each article should:

- answer the main question in the first 80 to 120 words
- define what the service can and cannot do
- mention mainland China, overseas Chinese, and cross-border context naturally
- reuse trust signals such as 10+ years of experience, professional organization, integrity-first service, and official website reference
- link back to the related service page and contact page
